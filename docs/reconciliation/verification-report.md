## Mechanical inventory method (reproducible)

The route/import-graph/quarantine/duplicate/dead-link/zero-caller sweep behind
`prebuilt-component-inventory.md` and `route-reconciliation.md` was produced by a
purpose-built Node script that:

1. Walks `artifacts/storefront` (excluding `node_modules`, `.next`, build output),
   collecting every `.ts`/`.tsx`/`.js`/`.jsx` file.
2. Builds a static import graph by regex-matching `import`/`export ... from`/dynamic
   `import()`/`require()` specifiers, resolving `@/`-aliased and relative paths
   against the filesystem (bare package/workspace specifiers are not resolved —
   out of scope for an intra-app orphan sweep).
3. Derives zero-importer files (excluding Next.js special files —
   `page`/`layout`/`route`/`loading`/`error`/etc., which are framework-invoked, not
   import-invoked — and `.test.ts(x)`/`e2e` files).
4. Derives the route table from `app/**/page.tsx` and `app/**/route.ts`, resolving
   dynamic-segment URLs and each route's layout chain.
5. Cross-references `api-server/src/routes/*.ts` (`router.get/post/patch/put/delete`
   call sites) against storefront `apiGet/apiPost/apiPatch/apiPut/apiDelete` call
   sites to find server routes with no storefront caller (not exhaustively used in
   this pass — flagged as a follow-up for Phase 7).
6. Extracts every `href` literal in active source and checks it against the route
   table (dynamic segments matched positionally) to compute dead links.
7. Greps for the `PlaceholderPage`/"Clean slate placeholder" signature across every
   active route file, then **reads each match in context** before counting it (one
   false positive found and excluded: `/metabolic`'s doc-comment reference to its
   own fix history).

This script and its raw JSON output were **not** committed to the repository (it is
a one-off inventory tool, not application code, and the repo's own file-cap/lint
gates are scoped to `artifacts/storefront`) — re-run the method above to regenerate
current numbers rather than trusting a stale copy if the tree changes.
`stitch-manifest.normalized.json` and `stitch-code-matrix.json`/`.md` **were**
generated by a second script that transforms `docs/stitch/stitch-screen-manifest.json`
(itself the product of the prior audit's own verification pass) into the schema
this sweep's spec requires, cross-checked against the mechanical inventory and this
session's manual verification of the 12 repo-specific claims — those two outputs
**are** committed, being the sweep's actual required deliverable.
